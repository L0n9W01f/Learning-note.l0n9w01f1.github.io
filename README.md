# Data Analytics Learning Journey  
## Module 1  
### 1. The Data Analysis Process  
> 1. Ask (To ask question of what we want to find and what we want to know. if there is any existing data we can access.)
> 2. Prepare (To collect data)
> 3. Process (To clean the data and make them ready to be analyse)
> 4. Analyse (To analyse the data)
> 5. Share (To share the data through reports, presentation, or with visualization tools)
> 6. Act (To act accordingly to the result. e.g,. suggest the manager to change the marketing strategy)

### Types of data  
> 1. numeric data (all number data that can be math)
> 2. Text or string data (data that consists of a mix of text and number which can not be math)
> 3. Date data (date and time)
> 4. Categories data (data that can be divided into groups. e.g., customer rating, products sorted by colors)

### Data Ecosystem  
> data ecosystem : a data ecosystem encompassed the various elements that interact with one another in order to produce, manage, store, organize, analyze, and share data.  
> contains hardware, software, tools, and people who use data.  
> Cloud : a place to keep data online  
> Data Science : creating new ways of modeling and understanding the unknown by using raw data  
> Data Analysis : The collection, transformation, and organization of data in order to draw conclusions, make predictions, and drive informed decision-making.
> Data analytics : the science of data. A broad idea of all data ecosystem and data analysis.

### Data and gut instinct
> data is informed and detailed
> gut instinct is based on your past experience and can be biased and have mistake.
